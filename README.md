# Hi, I'm Tryg 👋

Full-stack .NET builder based in Cape Town, South Africa. I build web apps,
APIs and mobile apps, and I like taking a project from idea to something
deployed and usable.

- **Mobile and desktop apps:** .NET MAUI with SQLite
- **AI-assisted tools:** Python and FastAPI projects, plus Claude Code tooling
- **Websites:** hand-built HTML/CSS/JS sites for real clients and communities
